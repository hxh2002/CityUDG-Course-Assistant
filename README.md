# CityU(DG) DS 选课助手 · 2026/27 Semester A

香港城市大学（东莞）2026 级数据科学理学硕士（DS TPG）选课与排课辅助工具。

## 🚀 一键启动

| 入口 | 地址 |
|---|---|
| **在线访问** | <https://hxh2002.github.io/CityUDG-Course-Assistant/> |
| **本地运行** | 直接双击打开 `index.html` 即可（无需安装依赖） |

![Deploy](https://github.com/hxh2002/CityUDG-Course-Assistant/actions/workflows/pages.yml/badge.svg)

## 功能

- 课程搜索、按类型 / 上课日筛选
- 可视化周一至周六课表、时段冲突检测
- 核心 / 选修 / 思政 / 总学分统计与规则检查（`1 门思政 + 3 门必修 + 2 门选修` = 16/17 CUs）
- 课程详情：班次、教师、先修、教材、评分
- GitHub 登录后发表评论与打分（未登录不可评论）

## 快速开始

- **线上**：打开上面的在线地址，选课记录保存在浏览器本地。
- **本地**：下载仓库后直接打开 `index.html`，数据内嵌、无需服务器。

## 数据说明

以 SIS / 最新正式通知为准；CIR / Course Catalogue / 班会材料仅作补充。课程时段、教师、教室等以学校最新信息为准。

## 免责声明

非官方辅助工具，最终以 SIS、ARRO、Course Catalogue 及任课教师最新通知为准。
